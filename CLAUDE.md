# CLAUDE.md — Memoria persistente del proyecto PALANCA

Este archivo se lee al inicio de cada sesión de Claude Code sobre este repo.
Es la memoria que no se pierde entre conversaciones. Actualízalo cuando algo
cambie de verdad — no como bitácora diaria.

## Qué es esto

**Palanca** es un producto de suscripción que enseña a usar Claude (Anthropic)
como herramienta de trabajo real: desde chat básico hasta construir aplicaciones
con Claude Code y delegar tareas con Cowork.

- **Marca madre:** DailyDuty / Instituto para el Desarrollo Diario
- **Creador:** Rodrigo Infante — Bogotá, Colombia. Ingeniero industrial,
  Analytics Engineer, Lean Six Sigma Green Belt.
- **Modelo:** suscripción mensual (recurrente, no pago único). El objetivo
  del negocio es LTV, no la primera venta.
- **Plataforma de cobro:** Hotmart o Skool (decisión abierta — ver docs/02).
- **Precio de lanzamiento propuesto:** $28.000 COP/mes.

## Tono de marca

Directo, casual, seguro. Tutear siempre. Frases cortas, párrafos de máximo
3 líneas. Números específicos, nunca vaguedades. Cero corporativo.

**Prohibido:** "solución integral", "potencia tu negocio", "lleva tu empresa al
siguiente nivel", "herramienta innovadora", "revolucionario", "en la era de la IA".

**Sí:** "Tú haces el trabajo de tres personas. Nadie te enseñó cómo."
"Esto no es un curso de prompts." "Te muestro la pantalla, no la teoría."

## Reglas duras del proyecto

1. **Nunca prometer resultados de ingresos.** Ni "gana $X con IA". Vendemos
   capacidad, no ingresos. Esto también es lo que mantiene la cuenta viva en Meta.
2. **Nunca republicar video ajeno como propio.** Ver docs/01, sección de riesgos.
3. **Los datos de producto de Anthropic se verifican antes de publicarlos.**
   Precios y planes cambian. Fuente de verdad: `claude.com/pricing` y
   `docs.claude.com`. Nunca citar de memoria en material que se vende.
4. **Módulos 0-2 deben funcionar en el plan gratis de Claude.** El estudiante
   tiene que sentir valor antes de que le pidamos pagar una herramienta.
5. **Todo contenido nuevo se registra en `contenido/REGISTRO.md`** antes de darlo
   por entregado, o se repite el ángulo y quema la audiencia.

## Contexto técnico que el estudiante recorre

Claude tiene tres superficies que el curso enseña en este orden:

1. **Chat** (claude.ai / app) — conversación, proyectos, estilos, artifacts,
   conectores (Drive, Gmail, Calendar, Notion) y skills.
2. **Cowork** — delegación de tareas largas de trabajo de conocimiento.
3. **Code** — terminal / IDE / app de escritorio. Requiere plan pago.
   Cada sesión de trabajo se comporta como una rama: trabajas, revisas, mergeas.
   `CLAUDE.md` en cada repo es donde vive el contexto que no se pierde.

El "momento ajá" del curso es exactamente este archivo: cuando el estudiante
entiende que puede darle memoria permanente a su asistente, deja de ser usuario
de un chat y pasa a ser dueño de un sistema.
